## About This Lab

This repository demonstrates the basic Git workflow:

1. Create a repository on GitHub
2. Clone it to a local machine
3. Edit a file
4. Stage the change with `git add`
5. Commit the change with `git commit`
6. Push the commit back to GitHub with `git push`

## Commands Used

```
git clone https://github.com/abigailnanama/DCIT323-22330178-Lab-1.git
cd DCIT323-22330178-Lab-1
git status
git add README.md
git commit -m "Update README with student details and lab steps"
git push origin main
```
